איך זה עובד

שלושה שלבים, בערך עשר דקות. אחרי השלב השלישי החסימה פעילה ונעולה.

1. מורידים ומתקינים

מורידים מהעמוד הזה קובץ אישי, ומתקינים אותו כמו כל אפליקציה. כל הורדה מקבלת קודים משלה, שלא עובדים על אף מכשיר אחר.

2. מפעילים

נותנים לקיידרואיד הרשאת "מנהל מכשיר". זו ההרשאה שמונעת להסיר את האפליקציה או לעקוף אותה. המדריך למטה מסביר בדיוק איך.

3. בוחרים ונועלים

ממלאים שם וטלפון, בוחרים מסלול והגבלות, ולוחצים "נעל". מאותו רגע אי אפשר לשנות כלום מהמכשיר.

בוחרים מסלול אחד בזמן ההתקנה. אפשר לבקש להחליף אותו אחר כך, דרך המוקד.

מדריך הפעלה

בחרו לפי המכשיר. המדריך מסביר גם מה כל דבר אומר, כדי שלא תצטרכו לנחש.

לפני שמתחילים: אם בטלפון יש חשבונות (למשל חשבון גוגל), ההפעלה בדרך כלל מסתדרת לבד. אם היא נכשלת בגלל חשבונות, מסירים אותם זמנית בהגדרות ← חשבונות, מפעילים, ומחזירים אותם. שום מידע לא נמחק.
אנדרואיד 11 ומעלהחיבור לוויפי (גם נקודה חמה מטלפון אחר)בלי מחשב

  1. מורידים ומתקינים את הקובץ

    לוחצים "הורדה לטלפון" למטה, פותחים את הקובץ שירד ומתקינים. אם הטלפון שואל אם לאפשר התקנה ממקור לא ידוע, מאשרים.

    מה זה אומר? אפליקציה שלא מחנות Play נקראת "ממקור לא ידוע". זה תקין, והקובץ חתום כך שאי אפשר לזייף אותו.

  2. פותחים את "אפשרויות מפתחים"

    בהגדרות ← אודות הטלפון, לוחצים 7 פעמים על "מספר גרסה" עד שמופיע "אתה מפתח". באפליקציה יש כפתור שפותח את המסך הזה ישר.

    דגםGalaxy A15

    מה זה אומר? "אפשרויות מפתחים" הוא תפריט מוסתר בכל טלפון אנדרואיד. פותחים אותו פעם אחת, וזה לא משנה שום דבר אחר בטלפון.

  3. באפליקציה: "ניפוי באגים אלחוטי" ← "התחל"

    האפליקציה פותחת את אפשרויות המפתחים. מדליקים שם "ניפוי באגים אלחוטי", נכנסים אליו, ובוחרים "צימוד מכשיר עם קוד צימוד". מופיע חלון עם קוד של 6 ספרות.

    מה זה אומר? "ניפוי באגים" מאפשר לאפליקציה לתת לעצמה את הרשאת מנהל המכשיר, בלי מחשב. היא משתמשת בזה פעם אחת, ואחרי הנעילה היא סוגרת את האפשרות.

  4. מקלידים את הקוד בהתראה

    לא סוגרים את החלון עם הקוד. מלמעלה יורדת התראה מקיידרואיד: לוחצים בה "הקלדת קוד הצימוד", מקלידים את 6 הספרות ושולחים. מכאן הכל קורה לבד, ובסוף מופיעה ההודעה "קיידרואיד הופעל".

    למה בהתראה? אנדרואיד מבטל את הצימוד ברגע שיוצאים מהחלון. בהתראה מקלידים את הקוד בלי לצאת ממנו.

  5. בוחרים ונועלים

    פותחים את קיידרואיד, ממלאים שם וטלפון, בוחרים מסלול והגבלות, ולוחצים "נעל את המכשיר". לפני הנעילה מופיע חלון אישור, וקוראים אותו בעיון.

מסכי רכב ומולטימדיהקופסאות אנדרואידלחיצה אחת להפעלה

  1. מעבירים את הקובץ ומתקינים

    מורידים "הורדה לטלפון" (זה אותו קובץ), מעבירים אותו למסך בדיסק און קי או בהורדה ישירה, ומתקינים.

  2. באפליקציה: בוחרים "מולטימדיה"

    מופיעים ארבעה שלבים עם כפתור לכל אחד.

  3. מעתיקים את הקוד

    לוחצים "העתק". בחלק מהמסכים הפעלת ניפוי הבאגים מבקשת קוד, ואז מדביקים אותו שם.

  4. פותחים "אודות" ואז "אפשרויות מפתחים"

    ב"אודות" לוחצים 7 פעמים על "מספר גרסה". ב"אפשרויות מפתחים" מדליקים "ניפוי באגים USB".

    מה זה אומר? במסכי רכב, "ניפוי באגים" פותח לאפליקציה דרך לתת לעצמה את הרשאת מנהל המכשיר, בלי כבל ובלי מחשב.

  5. לוחצים "הפעל" ואחר כך נועלים

    אם קופץ חלון אישור, מאשרים. אחר כך ממלאים פרטים, בוחרים מסלול ונועלים.

מחשב Windowsכבל USB שמעביר נתוניםלא צריך אינטרנט במחשב

  1. מורידים "תוכנה למחשב" ופותחים אותה

    קובץ אחד, בלי ZIP ובלי התקנה. אם Windows מציג "Windows protected your PC", לוחצים "מידע נוסף" ← "הפעל בכל זאת".

  2. עוקבים אחרי ההדרכה בתוכנה

    התוכנה מראה צעד אחרי צעד, לפי יצרן הטלפון, איך מדליקים "ניפוי באגים ב-USB", מזהה לבד את הטלפון כשמחברים אותו בכבל, ומסבירה מה לאשר בטלפון.

  3. לוחצים "התקנה"

    התוכנה מתקינה ומפעילה הכל לבד. אם יש אינטרנט היא מתקינה את הגרסה העדכנית ביותר; בלי אינטרנט, את הגרסה שבתוכה. כשסוגרים את החלון בסוף, היא נמחקת מהמחשב.

  4. בטלפון: בוחרים ונועלים

    ממלאים פרטים, בוחרים מסלול והגבלות, ולוחצים "נעל את המכשיר".

מחשב עם Chrome או Edgeכבל USB שמעביר נתוניםבלי להתקין שום תוכנה

  1. בטלפון: מדליקים "ניפוי באגים ב-USB"

    הגדרות ← אודות הטלפון ← לוחצים 7 פעמים על "מספר גרסה". אחר כך: הגדרות ← אפשרויות מפתחים ← "ניפוי באגים ב-USB".

    מה זה אומר? "ניפוי באגים ב-USB" מאפשר למחשב להתקין את האפליקציה ולתת לה את הרשאת מנהל המכשיר. אחרי הנעילה קיידרואיד סוגר את האפשרות הזו.

  2. מחברים את הטלפון למחשב בכבל

    אם במחשב פתוחה תוכנה אחרת שעובדת מול טלפונים (למשל תוכנת גיבוי או adb), סוגרים אותה קודם.

  3. לוחצים "התקנה מהדפדפן" למטה

    הדפדפן מציג רשימה עם הטלפון. בוחרים אותו ולוחצים "התחברות". בטלפון מופיעה הודעה "לאפשר ניפוי באגים?": מסמנים "אפשר תמיד מהמחשב הזה" ולוחצים "אישור".

  4. מחכים בערך דקה

    הדף מכין קובץ אישי, מעתיק אותו לטלפון, מתקין ומפעיל. כל שלב מסומן על המסך. בסוף קיידרואיד נפתח בטלפון.

  5. בטלפון: בוחרים ונועלים

    ממלאים פרטים, בוחרים מסלול והגבלות, ולוחצים "נעל את המכשיר".

    לא עובד? בחלק מהמחשבים עם Windows הדפדפן לא רואה את הטלפון בלי מנהל התקן (Driver) של היצרן. במקרה כזה משתמשים בלשונית "דרך מחשב". שם התוכנה מגיעה עם כל מה שצריך.

שאלות נפוצות

אפשר להסיר את החסימה אחרי שנעלתי?
לא מהמכשיר עצמו. מבקשים מהאפליקציה (תפריט ⋮ ← בקשת שינוי), והבקשה מגיעה למוקד. אין התחייבות להסיר את החסימה, וייתכן שייגבה על כך תשלום סמלי. את זה מאשרים במפורש לפני הנעילה.
איך מחליפים מסלול?
שולחים בקשה מהאפליקציה. כשהמוקד מאשר, השינוי מגיע למכשיר לבד. גם על החלפת מסלול אין התחייבות, וייתכן שייגבה תשלום סמלי.
מה אם בטלפון אין אינטרנט בכלל?
החסימה עובדת גם בלי אינטרנט. לשינויים יש "קוד חירום": במסך "קוד חירום" באפליקציה מופיעים מספרים, מקריאים אותם למוקד בטלפון, והמוקד מקריא קוד שמבצע את השינוי. כל קוד מתאים רק למכשיר שלכם ורק לפעם אחת.
למה צריך "הרשאת מנהל מכשיר"?
זו ההרשאה שמונעת להסיר את האפליקציה, לעקוף אותה או לכבות אותה. בלעדיה כל אחד היה יכול פשוט למחוק את החסימה.
האם ההתקנה מוחקת משהו מהטלפון?
לא. אנשי קשר, תמונות, הודעות ואפליקציות נשארים. מה שמשתנה הוא רק מה שבחרתם לחסום.
מה המוקד רואה על הטלפון שלי?
את השם והטלפון שמילאתם, את המסלול וההגבלות, ואת רשימת האפליקציות המותקנות (כדי לטפל בבקשות). לא תמונות, לא הודעות ולא שיחות.
ההפעלה נכשלה. מה עושים?
ברוב המקרים הסיבה היא חשבונות בטלפון. מסירים אותם זמנית (הגדרות ← חשבונות), מנסים שוב ומחזירים אותם. בניפוי באגים אלחוטי: בודקים שהטלפון בוויפי ושחלון הקוד עדיין פתוח כשמקלידים בהתראה. ההודעה באפליקציה מראה גם פרטים טכניים, ואפשר לצלם אותה ולשלוח למוקד.
זה עובד באייפון?
לא. קיידרואיד עובד רק באנדרואיד.

הורדה

כל לחיצה מכינה קובץ אישי משלכם, עם קודים שלא עובדים על אף מכשיר אחר. ההכנה לוקחת כמה שניות, והקובץ שוקל בערך 43MB.

התקנה מהדפדפן הכי פשוט

מחברים את הטלפון בכבל למחשב, לוחצים כאן, וזהו. בלי להוריד ובלי להתקין שום תוכנה. עובד ב-Chrome או Edge במחשב.

הורדה לטלפון

לטלפון רגיל (ניפוי באגים אלחוטי) ולמסכי מולטימדיה. אחרי ההפעלה הקובץ נמחק מהמכשיר לבד.

תוכנה למחשב

ל-Windows, דרך כבל USB, בלי אינטרנט במחשב. בסוף ההתקנה היא נמחקת מהמחשב.
